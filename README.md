LaunchLens is a token launch radar: it ranks pre-token protocols by an implied value derived from TVL, seven-day growth and age, calibrated against the market-cap-to-TVL ratios of tokens that already trade, and shows a concrete seven-step farm plan with costs and times for every protocol.
## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot>
```
The snapshot is the sealed `/input/snapshot.json` in the grader; pass its path (or the directory holding it) with `--input` when you run it yourself.
